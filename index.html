☁️ GitHub Sync

Share products between devices. When you add a product, it syncs to a shared file on GitHub so everyone using this app sees it.

📋 Setup Instructions

  1. Create a GitHub repo (e.g. asr-pricing)
  2. Create a file called products.json with content: []
  3. Go to GitHub → Settings → Developer Settings → Personal Access Tokens → Fine-grained tokens
  4. Create a token with Contents: Read and Write access for that repo
  5. Paste the owner, repo name, and token above
  6. Both users point to the same repo — products sync automatically
